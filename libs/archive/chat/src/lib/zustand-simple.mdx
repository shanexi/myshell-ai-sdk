# Practice with no store actions

[Practice with no store actions](https://zustand.docs.pmnd.rs/guides/practice-with-no-store-actions)

Zustand can be used with no store actions, it seems that it can also be combined with class + inversify. Class is only used to encapsulate logic, inversify is used to inject store, all are singletons, for transient, we need `slice` to create new store.actions

This is equivalent the combination of class + MobX + inversify, only replacing MobX.

# Combined slice with differenct middleware

The best approach is to avoid different slices, and it should be avoided.

If dealing with legacy code, or create differenct stores with differenct middlewares (which can be done but is mentally challenging to maintain).

then use `unkonwn`

```typescript
export const useBoundStore = create<BoundStore>()(
  devtools(
    immer(
      persist(
        (...a: unknown[]) => ({
          ...createBearSlice(...a),
          ...createFishSlice(...a),
          ...createSharedSlice(...a),
        }),
        {
          name: 'test',
          partialize: (s: BoundStore) => ({
            ...partializeBearSlice(s),
            ...partializeFishSlice(s),
          }),
        }
      )
    )
  )
);
```

# TypeScript Utility

[Exclude function types from an object type](https://stackoverflow.com/questions/58210331/exclude-function-types-from-an-object-type)

```typescript
type FunctionPropertyNames<T> = {
  [K in keyof T]: T[K] extends Function ? K : never;
}[keyof T];
type FunctionProperties<T> = Pick<T, FunctionPropertyNames<T>>;

type NonFunctionPropertyNames<T> = {
  [K in keyof T]: T[K] extends Function ? never : K;
}[keyof T];
type NonFunctionProperties<T> = Pick<T, NonFunctionPropertyNames<T>>;
```
